# Week 3 - Day 5: CareFlow KPI Planning

## Objective
To identify important KPIs for understanding hospital patient journeys.

## Proposed KPIs
1. Total Patients
2. Total Events
3. Average Transition Time
4. Average Patient Journey Duration
5. Delayed Patient Count
6. Loop-back Patient Count
7. Average Time Between Hospital Activities

## Pending Work
- Calculate actual KPI values.
- Verify KPI results using available data.
- Finalize dashboard metrics.

## Conclusion
The proposed KPIs will help explain patient flow, delays and process performance.
