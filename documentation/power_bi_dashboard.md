# CareFlow – Power BI Dashboard Documentation

## 1. Objective
To visualize hospital patient journeys and understand patient flow, delays, and process variations.

## 2. Dashboard Components
- Total Patients
- Total Events
- Delayed Patients
- Loop-back Patients
- Average Transition Time
- Patient Journey by Activity
- Journey Type Distribution
- Department-wise Analysis
- Patient Flow Process Map

## 3. Interactive Features
- Journey Type Filter
- Department Filter
- Date Filter

## 4. Data Source
CareFlow Synthetic Patient Event Log containing 500 patients and 3,351 event records.

## 5. Outcome
The Power BI dashboard provides a visual overview of patient activities, journey patterns, and important process performance indicators.
