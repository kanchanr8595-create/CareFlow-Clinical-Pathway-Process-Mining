# CareFlow – Final Project Summary

## 1. Project Overview
CareFlow is a Clinical Pathway Process Mining project that analyses synthetic hospital event data to understand patient treatment journeys.

## 2. Project Objective
- Understand patient treatment pathways.
- Identify possible delays and bottlenecks.
- Analyse repeated activities and loop-back journeys.
- Visualize patient flow and process performance.

## 3. Team Contributions
- Kanchan: Patient journey logic, Python data generation and analysis, documentation, integration and dashboard work.
- Gouri: BigQuery and SQL analysis.
- Akshaya: Data quality validation.
- Alfiya: dbt setup and transformation work.

## 4. End-to-End Project Workflow
Python → BigQuery → dbt → PM4Py → Power BI

## 5. Final Outcome
The project includes a synthetic patient event dataset, validation documentation, patient journey analysis, process mining documentation, and a Power BI dashboard.

## 6. Conclusion
CareFlow demonstrates how data analytics and process mining can help understand hospital workflows and identify areas for process improvement.

Note: All patient records are synthetic and do not contain real patient information.
