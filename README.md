# CareFlow – Clinical Pathway Process Mining

## Project Overview
CareFlow is a data analytics and process mining project that analyses synthetic hospital patient event data to understand patient treatment journeys, process variations, delays, and repeated activities.

## Project Objective
- Analyse patient treatment journeys.
- Identify potential delays and bottlenecks.
- Understand repeated activities and loop-back patterns.
- Visualize hospital workflow performance.

## Dataset
- Total Patients: 500
- Total Events: 3,351
- Data Type: Synthetic hospital event data
- No real patient information is used.

## Technology Stack
- Python: Synthetic data generation and analysis.
- Excel: Data review and analysis.
- BigQuery: Data storage and SQL analysis.
- dbt: Data transformation.
- PM4Py: Process mining and process visualization.
- Power BI: Interactive dashboard development.

## Project Workflow
Python → BigQuery → dbt → PM4Py → Power BI

## Dashboard Features
- Total Patients and Total Events
- Delayed and Complex Patients
- Loop-back Analysis
- Patient Journey by Activity
- Journey Type Distribution
- Department-wise Analysis
- Patient Flow Visualization
