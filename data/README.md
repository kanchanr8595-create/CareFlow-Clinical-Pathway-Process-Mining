# Data Folder

This folder contains the synthetic healthcare event log dataset used for the CareFlow Clinical Pathway Process Mining project.

## Purpose
- Analyze patient treatment journeys
- Identify workflow delays and bottlenecks
- Study clinical pathway patterns

## Data Privacy
Only synthetic or anonymized sample data should be used in this project.
