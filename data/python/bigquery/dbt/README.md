# dbt Data Transformation

This folder contains dbt models for transforming and preparing healthcare event log data for analysis.

## Objectives
- Clean and transform source data
- Create reusable data models
- Prepare data for clinical pathway analysis
- Support consistent workflow performance metrics

## Tools
- dbt (data build tool)
- SQL
- BigQuery

## Planned Models
- Staging model for healthcare events
- Patient journey analysis model
- Workflow waiting time model

## Note
The dbt project files and SQL models will be added after the BigQuery dataset and tables are finalized.
