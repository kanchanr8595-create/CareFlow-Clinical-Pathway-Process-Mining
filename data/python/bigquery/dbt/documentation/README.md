# Project Documentation

This folder contains the documentation for the CareFlow Clinical Pathway Process Mining project.

## Project Overview
The project analyzes synthetic healthcare event logs to understand patient treatment journeys and identify workflow delays and bottlenecks.

## Project Objectives
- Understand the patient journey through clinical activities
- Identify delays and inefficient workflow steps
- Analyze waiting times between activities
- Present insights that may help improve hospital workflows

## Project Workflow
1. Prepare the healthcare event log dataset
2. Clean and analyze data using Python
3. Run SQL analysis in BigQuery
4. Transform data using dbt
5. Summarize findings and recommendations

## Planned Deliverables
- Dataset description
- Python analysis and visualizations
- BigQuery SQL queries
- dbt transformation models
- Final findings and project report
