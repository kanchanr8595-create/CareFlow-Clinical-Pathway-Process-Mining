# Week 3 – SQL Event Count and Loop-Back Analysis

## Objective

To analyse patient activity distribution and identify repeated activities (loop-backs) in the CareFlow dataset using BigQuery SQL.

## Work Completed

- Executed SQL queries using `GROUP BY` and `COUNT()` to calculate event counts for each activity.
- Used `ORDER BY` to sort activities in descending order based on event count.
- Analysed loop-back occurrences across different patient activities.
- Identified repeated activities in patient journeys.
- Reviewed query outputs to understand patient activity patterns.

## Results

- **Total Records:** 3,351
- **Different Activities:** 8
- **Highest Event Count:** Doctor Consultation – 609
- **Doctor Consultation Loop-Backs:** 218

## Key Findings

- Doctor Consultation had the highest number of recorded events in the dataset.
- Loop-back analysis helped identify repeated activities in patient journeys.
- The results provided insights into patient activity distribution and recurring patterns.

## Conclusion

Successfully completed event count and loop-back analysis using BigQuery SQL. The analysis helped understand the distribution of clinical activities and identify repeated activities within the CareFlow patient journey dataset.
