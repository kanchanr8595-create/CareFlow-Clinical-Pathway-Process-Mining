Week 3 – Event Count by Activity

Objective: To analyse the distribution of patient activities in the CareFlow dataset.

Work Completed:

- Executed SQL queries using "GROUP BY" and "COUNT()".
- Counted the total number of events for each activity.
- Used "ORDER BY" to sort activities by event count in descending order.

Results:

- Total records: 3,351
- Different activities: 8
- Highest event count: Doctor Consultation – 609
- Lowest event count: Follow-up – 97

Outcome:
Successfully analysed the distribution of events across different hospital activities. This provides an overview of how frequently each activity occurs in the dataset.
